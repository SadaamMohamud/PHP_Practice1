# Course Description

Web Application Development - PHP & MySQL is a course that introduces students to building dynamic and database-based websites using PHP and MySQL.

The course starts with the basic concepts of PHP and gradually moves to more advanced topics such as forms, databases, CRUD operations, APIs, authentication, security, MVC, and Laravel.

Students will learn both the theory and practical skills needed to develop PHP web applications. The course also includes programming exercises and practical projects to help students apply what they learn.

---

# Course Objectives

By the end of this course, students will be able to:

- Understand the basic concepts of web application development.
- Understand how PHP works as a server-side programming language.
- Create dynamic web pages using PHP.
- Use PHP variables, data types, operators, conditions, loops, arrays, and functions.
- Create and process HTML forms using PHP.
- Validate and handle user input.
- Understand databases and relational database concepts.
- Create and manage MySQL databases and tables.
- Write basic SQL commands such as:
  - SELECT
  - INSERT
  - UPDATE
  - DELETE
  - CREATE
  - JOIN
- Connect PHP applications with MySQL databases.
- Build applications using CRUD operations.
- Understand AJAX, JSON, and interactive web applications.
- Create basic REST APIs using PHP.
- Understand sessions, cookies, authentication, and authorization.
- Apply basic security practices in web applications.
- Understand MVC architecture.
- Learn the basic structure and use of the Laravel framework.
- Develop a complete PHP and MySQL web application.

# Final Learning Outcome

At the end of the course, students will have a strong foundation in **PHP and MySQL web development**.

Students will understand how to move from a simple PHP program to a database-driven web application by using:

```text
HTML + CSS
     ↓
JavaScript / AJAX
     ↓
PHP
     ↓
MySQL
     ↓
CRUD / APIs
     ↓
Authentication & Security
     ↓
MVC
     ↓
Laravel
```

The knowledge from this course will provide the foundation for developing dynamic, interactive, and database-driven web applications.
